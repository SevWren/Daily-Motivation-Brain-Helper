# Support

## How to get help

1. **Read the user manual** — [manual/README.md](manual/README.md)
2. **Check troubleshooting** — [manual/troubleshooting/common-errors.md](manual/troubleshooting/common-errors.md)
3. **Search existing issues** on GitHub before opening a new one
4. **Open a GitHub issue** using the bug or feature template

## What to include in a bug report

- Windows version (10/11) and PowerShell version (`$PSVersionTable.PSVersion`)
- Whether you ran the compiled `DailyMotivation.exe` or the `.ps1` source
- Steps to reproduce
- Expected vs actual behavior
- Relevant log snippets from `%APPDATA%\DailyMotivationBrainHelper\popup_log.txt` (paths are hashed; do not paste secrets)

## Security issues

Do **not** file public issues for vulnerabilities. See [SECURITY.md](SECURITY.md).

## Scope

This is a small open-source Windows utility. Support is best-effort from maintainers and community contributors. There is no commercial SLA.
