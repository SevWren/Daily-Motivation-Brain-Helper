# Roadmap

## v1.0 — MVP
**Goal:** Core scheduling and popup loop working end-to-end.

- Folder picker
- Schedule for tomorrow at 2 PM
- Motivational popup with Open Folder / Snooze
- 5-minute snooze loop
- View and delete scheduled tasks
- Default message library (10 messages)

## v1.1 — Polish & Power User
**Goal:** Remove remaining friction points.

- Custom motivational message management (add/edit/delete)
- Custom schedule time (not just 2 PM)
- System tray icon
- Auto-start on Windows login
- Missed-trigger recovery UX improvement

## v2.0 — Expansion
**Goal:** Multi-session and personalization.

- Multiple active schedules per day
- Message categories and tagging
- Dark/light theme toggle
- Export/import message library
- Optional desktop widget showing next scheduled task
