# Project Charter

## Project Name

Daily Motivation Brain Helper

## Problem Statement

Users end their workday with a specific folder open and want it to automatically reopen the next day at 2 PM, accompanied by a motivational message — without writing any code or editing any configuration files.

## Goals

- Deliver a zero-code scheduling experience for non-technical Windows users
- Provide a motivational popup that persists (via snooze) until acknowledged
- Allow users to manage (view/delete) scheduled tasks through a simple UI

## Out of Scope

- Cloud sync or remote access
- Mobile platforms
- Multi-user environments

## Success Criteria

- User can schedule a folder in 3 clicks or fewer
- Popup fires at 2 PM and re-fires every 5 minutes until acknowledged
- No manual file editing required at any point
