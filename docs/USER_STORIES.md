# User Stories

## Core Stories

### US-001 — Schedule a Folder
As a user,
I want to select a folder using a file picker,
So that it opens automatically tomorrow at 2 PM.

### US-002 — Receive a Motivational Popup
As a user,
I want to see a motivational message before my folder opens,
So that I feel ready to work.

### US-003 — Accept the Popup
As a user,
I want to click "Open Folder" on the popup,
So that my folder opens in Windows Explorer.

### US-004 — Snooze the Popup
As a user,
I want to click "Snooze" on the popup,
So that it reappears in 5 minutes when I am ready.

### US-005 — View Scheduled Tasks
As a user,
I want to see all currently scheduled folder openings,
So that I know what is queued.

### US-006 — Delete a Scheduled Task
As a user,
I want to delete a scheduled task,
So that the folder no longer opens automatically.

### US-007 — Manage Motivational Messages
As a user,
I want to view and customize motivational messages,
So that the popup feels personal.
