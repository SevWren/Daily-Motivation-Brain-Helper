# User Stories

**Last Updated:** 2026-06-04
**Last Reviewed**: 2026-06-09

### US-001 — Schedule a Folder

As a user, I want to select a folder using a file picker, so that it opens automatically tomorrow at 2 PM.

### US-002 — Receive a Motivational Popup

As a user, I want to see a motivational message before my folder opens, so that I feel ready to work.

### US-003 — Accept the Popup

As a user, I want to click "Open Folder" on the popup, so that my folder opens in Windows Explorer.

### US-004 — Snooze the Popup (Updated — B-10)

As a user, I want to snooze the popup and choose how long (5, 15, 30, or 60 minutes), so that it reappears when I am actually ready.

### US-005 — View Scheduled Tasks

As a user, I want to see all the currently scheduled folder openings, so that I know what is queued.

### US-006 — Delete a Scheduled Task

As a user, I want to delete a scheduled task for opening folders, so that the folder no longer opens automatically.

### US-007 — Manage Motivational Messages

As a user, I want to view the list of stored motivational messages, so that I can customize what will appear in futre notifications.

### US-008 — Quick Reschedule Last Folder (B-01)

As a returning user, I want to re-schedule the same folder I used last time in one click, so that I do not have to navigate the folder picker again.

### US-010 — Schedule For Today (B-03)

As a user opening the app before 2 PM, I want to schedule a folder for today at 2 PM (not just tomorrow), so that I can use the tool same-day.

### US-013 — First-Run Onboarding (B-07)

As a first-time user, I want a brief in-app explanation of how the tool works, so that I understand what to expect without reading any documentation.

### US-014 — Drag-and-Drop to Select Folder (B-09)

As a user who already has my folder open in Explorer, I want to drag it onto the app to select it, so that I can skip the picker dialog entirely.

### US-016 — Schedule via Explorer Right-Click (B-13)

As a user at end of day, I want to right-click my working folder in Explorer and schedule opening that folder tomorrow immediately, in a 2 click process or less, so that I never need to open the app at all.

### US-017 — View Task History (B-18)

As a user, I want to be able to open a file to see a history of which folders I opened and when, so that I have a simple record of my work sessions.

### US-018 — Self-Explaining Controls (B-19)

As a non-technical user, I want every button to explain what it does when I hover over it, so that I never feel confused or need to ask for help.
