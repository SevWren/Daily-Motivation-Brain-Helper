# Vision

## One-Line Vision
The simplest possible way to open tomorrow's work folder — with a burst of motivation.

## Target User
Non-technical Windows users who work with folders daily and want lightweight habit reinforcement without any automation tooling knowledge.

## North Star
A user should be able to schedule their next session's folder in the same time it takes to lock their screen.

## Anti-Vision
This product is NOT:
- A full task manager
- A productivity suite
- A replacement for Windows Task Scheduler UI
- A cloud-connected service
